<objective>
Two expansion slices on top of 03-01's proven fan-out.

1. **Curation (STRAT-02).** The Strategist proposes, then selects at most `max_approaches` (default 3) approaches worth teaching, in one call. Each carries a role label and a "why included" rationale. The node enforces the cap and drops duplicates deterministically. Role and rationale flow into the Editorial Writer as input only; the Writer still owns order and bridges (D-01..D-04).
2. **Resilient time budget (D-07, D-09, D-10).** The global budget becomes 20 minutes. A run-scoped `PipelineContext` (LangGraph Runtime context, never state or configurable) carries the invocation deadline. Branches stop at deadline minus a 240 s Writer reserve, and timed-out branches become "not verified" while verified ones ship. The Writer gets a per-attempt timeout and a node-level deadline, executor subprocesses are capped per process, parent-level status transitions reach Postgres, and invocations carry an explicit recursion limit.

Purpose: ROADMAP SC1 (curated multiple approaches) and D-10's "ship the verified ones" guarantee, which protects the Core Value work already done when time runs out.
Output: curation contract + prompt + guard, `graph/context.py`, deadline-bounded branches and Writer, executor semaphore, status transitions, worker context/recursion wiring.
</objective>

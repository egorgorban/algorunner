<objective>
Give the phase a durable, failure-tolerant artifact store before anything writes to it (DATA-02, D-18..D-21). The store is a boto3-backed S3 client whose writes run in a thread, each bounded by a timeout, and which warns and continues on any failure. A no-op store covers the case where Garage is not configured, a per-invocation recorder tracks exactly which keys were written, and the D-19 key builders validate every coordinate. Garage provisions its own bucket and key through the built-in `--single-node --default-bucket` flags (research-verified idempotent). Only the worker gets credentials; the API keeps serving results from Postgres (D-13).

Purpose: the storage half of ROADMAP SC4. Plan 03-08 wires these writes into the graph (analysis, every iteration, per-approach summaries, editorial) and lists the written keys in `tasks.result`. Landing the store and its human legitimacy gate this early keeps both human pauses of the phase (this one and 03-01's) at the start of execution.
Output: boto3 locked in, `storage/artifacts.py`, Garage settings, compose/env provisioning, `tests/storage/test_artifacts.py`, and a recreated dev Garage with a bucket and key.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker -> Garage S3 API | a new outbound storage channel carrying user problem text and generated code, authenticated with S3 credentials |
| env / compose -> credentials | S3 access key and secret enter the worker container |
| task data -> object keys | identifiers derived from task state become storage paths |
| package index -> worker/dev environment | a new third-party dependency (boto3) enters the lockfile |

| T-03-02-01 | Information Disclosure | storage/artifacts.py logging | high | mitigate | Warnings log only the key and exception type, with no exc_info, client or config objects (acceptance grep for exc_info = 0). | T-03-02-03 | Denial of Service | Garage outage/slowness | medium | mitigate | Per-write `asyncio.wait_for(timeout=artifact_write_timeout_s)` + botocore standard retries (3) + warn-and-continue (D-18). The pipeline never blocks on storage |

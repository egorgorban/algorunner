<user_decision_record>
**Confirmed by the user on 2026-09-24 (RESEARCH Open Q1, now RESOLVED). This is a locked decision for this plan, not an assumption.**

D-16 locks "retry the Writer once" but did not say what follows a second failure. The user confirmed the split by failure type:
- A **language or completeness** failure that survives the one retry (for example a Cyrillic ratio below threshold) ships the verified article with `result.editorial_warnings` naming each failure. This plan emits `language_check_failed`; Plan 03-07 adds `edge_cases_missing` and `notes_missing` under the same rule.
- A **structural** failure (the draft's approach IDs do not match the verified outcomes, or a bridge rule is broken) fails the task with error code `EDITORIAL_ASSEMBLY_FAILED`.

Rationale recorded with the decision: the Core Value is verified solution correctness, and D-10's spirit is to deliver verified work rather than discard it over prose quality. A structurally wrong article is never published. One retry is shared by all checks, so D-16's single retry is never exceeded.
</user_decision_record>

Per the user-confirmed decision above, structural failures that survive the retry fail the task with `EDITORIAL_ASSEMBLY_FAILED`, and language failures that survive it ship the verified article with explicit `editorial_warnings`.

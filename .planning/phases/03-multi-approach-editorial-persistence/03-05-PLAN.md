<objective>
Make the pipeline resilient to its time budget (D-07, D-09, D-10). The global budget becomes 20 minutes. A run-scoped `PipelineContext` (LangGraph Runtime context, never state or `configurable`) carries the invocation deadline. Branches stop at the deadline minus a 240 s Writer reserve, and timed-out branches become "not verified" while verified ones ship. The Writer gets a per-attempt timeout, its per-agent model override and a node-level deadline. Executor subprocesses are capped per process, parent-level status transitions reach Postgres, and every invocation carries an explicit recursion limit.

Task 2 finishes retyping the branch nodes this plan does not otherwise touch (Code Generator, Test Generator) to `ApproachState`.

Purpose: D-10's "ship the verified ones" guarantee. It protects the Core Value work already done when time runs out.
Output: `graph/context.py`, deadline-bounded branches and Writer, `Settings.editorial_writer_model`, the executor semaphore, status transitions, worker context/recursion wiring, and ApproachState annotations on the Code Generator and Test Generator.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generated code -> executor subprocesses (parallel) | several attacker-influenced programs of one task run concurrently |
| worker -> Postgres status writes | extra mid-run writes from graph nodes |
| worker -> OpenAI (Writer) | the only LLM call made inside the Writer reserve |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-05-01 | Denial of Service | graph/approach.py execute nodes | medium | mitigate | A process-wide asyncio.Semaphore(settings.executor_max_concurrency) caps concurrent Python/Go subprocesses, so parallel branches cannot starve CPU into spurious Go build timeouts (Pitfall 5) |
| T-03-05-02 | Denial of Service | Editorial Writer / branch deadlines | medium | mitigate | Branch wait_for at deadline minus reserve, Writer per-attempt timeout + node-level wait_for, and the worker's outer wait_for as the hard cap (D-10, INFRA-04) |
| T-03-05-03 | Denial of Service | recursion inside a branch | low | mitigate | recursion_limit = 8 * max_iterations + 30 per invocation; a GraphRecursionError inside a branch becomes an errored outcome, not a stuck task |
| T-03-05-04 | Repudiation | status sink writes | low | accept | A status write failure is logged, never raised. Postgres stays the source of truth for the terminal status written by the worker |
</threat_model>

<objective>
Make every intermediate artifact durable in Garage (DATA-02, D-17..D-21) without ever letting storage decide a task's fate. Then prove the whole phase live on the rebuilt stack.

1. **Store + provisioning.** Add a boto3-backed S3 artifact store (writes run in a thread, each bounded by a timeout; warn and continue), a no-op store for when Garage is not configured, a per-invocation recorder of successful keys, and the D-19 key builders. Garage provisions its bucket and key itself through the built-in `--single-node --default-bucket` flags (research-verified idempotent). Only the worker gets credentials; the API serves results from Postgres (D-13).
2. **Incremental persistence.** Write the analysis after the Analyzer's final pass, each approach iteration after its Reviewer, a per-approach summary when a branch ends (including timed-out and errored branches), and the editorial at the end. `result` lists only keys that were really written, plus `artifacts_incomplete` (D-20).
3. **Live phase acceptance.** A real problem on the rebuilt Docker Compose stack must meet ROADMAP Phase 3 success criteria 1-4 together, down to "the code in the article equals the code stored in Garage for the executed solution".

Purpose: ROADMAP SC4 (all intermediate artifacts persisted to Garage) plus the phase-level live proof.
Output: `storage/artifacts.py`, compose/env provisioning, persist wiring across the parent and approach graphs, `tests/storage/test_artifacts.py`, `tests/graph/test_persistence.py`, `scripts/verify_phase3_live.py`.

<objective>
Compose the verified approaches into the editorial (D-11, D-12, D-15, D-04). A new Editorial Writer makes one structured-output call for Russian prose covering every verified approach at once. Code, difficulty, tags, role and the Big-O notation are then injected deterministically, so the article's code is the executed code (D-12). The parent graph routes the join to the Writer when at least one approach is verified, and the worker stores the editorial in `tasks.result` (D-13).

Task 1 builds and unit-tests the Writer agent: contract, prompt, deterministic assembly and node. Task 2 wires it into the parent graph and proves it end-to-end on the real-execution path, including the branch-isolation case where only one approach verifies.

Purpose: ROADMAP SC2's article shape (EDIT-02, EDIT-03) and SC3's difficulty and tags (EDIT-04), with the Core Value guarantee that the article never shows code other than the executed, verified code.
Output: `schemas/editorial.py`, the `agents/editorial_writer/` package (prompt, assembly, node), the parent-graph wiring, `result.editorial`, and `tests/agents/test_editorial_writer.py`.
</objective>

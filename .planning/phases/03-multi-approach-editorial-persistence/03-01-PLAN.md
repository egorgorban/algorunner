## Phase Goal

ROADMAP Phase 3 goal (verbatim): "The pipeline surfaces multiple solution approaches and composes them into a complete, Russian-language editorial article that is durably persisted".

MVP mode is on, but this ROADMAP `**Goal:**` line is not in user-story format. No story is invented here; run `/gsd mvp-phase 3` to convert the Goal line if a story is wanted.

<objective>
Prove the phase's riskiest architecture end-to-end in one tracer slice: the Phase 2 linear single-solution graph becomes a parent graph that fans out one LangGraph `Send` branch per Strategist approach (each branch a compiled per-approach subgraph that reuses every Phase 2 node and the correction router unchanged), joins all branches once, and hands every verified approach to a new Editorial Writer that makes one structured-output call for Russian prose. Code, difficulty, tags and the Big-O notation are then injected deterministically, so the article's code is the executed code (D-12). The worker writes the editorial JSON into `tasks.result` (D-13).

Task 2 then hardens the slice: branch exception isolation, zero-verified routing, per-branch iteration budget, re-invoke idempotency, and the Phase 2 regression tests (correction loop, clarification, structured execution) moved onto the per-branch shape.

Purpose: D-08 is rated `costly` to reverse (it restructures state and edges). Proving it on one real path first, against real Postgres checkpoints and real Python/Go execution, means the three expansion plans (03-02 curation + time budget, 03-03 Russian guarantee + editorial completeness, 03-04 Garage persistence) build on a verified shape.
Output: the per-approach subgraph + `run_approach` wrapper, the parent fan-out/join graph, the Editorial Writer (prompt, node, deterministic assembly), the new `Editorial`/`ApproachOutcome` contracts, the D-13 result, and the repaired dev environment with `boto3` locked in.
</objective>

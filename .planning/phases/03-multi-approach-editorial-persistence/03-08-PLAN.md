<flagged_assumptions>
- **Open Q2 (RESOLVED):** FAILED tasks keep `result = null`; their trail is found by the `tasks/{task_id}/` prefix.
- **Crash redelivery (Open Q3, RESOLVED):** a redelivered restart rewrites the same keys for the same (idx, n). Immutability is guaranteed within one invocation only, since Garage does not enforce IfNoneMatch.
- **Hard-cancel residual (narrowed truth):** when the worker's outer wait_for fires (only after the 240 s reserve is spent), the graph is cancelled and no further artifact is written. On the Writer-overrun path every branch summary already exists; on an Analyzer/Strategist overrun no branch has started, so there is nothing to summarize. The zero-verified branch-deadline path does not depend on this cancellation and is covered by the worker-path test.
- **Prohibition recall (canon referral, not minted):** secrets in logs or artifacts, prompt injection through stored or clarified text, and indefinite retention of user text are canon security/compliance items owned by `/gsd-secure-phase`. Here they are covered by T-03-08-01/02 and 03-02's threat model, so `must_haves.prohibitions` is deliberately empty for this plan.
- **Live-test sensitivity:** the SC1 check (>= 2 proposed approaches) relies on the Strategist curating two-sum's canonical brute-force + hash-map pair. D-02 legitimately allows one approach, so a single-approach run is investigated (prompt vs model behavior) rather than the assertion being loosened silently.

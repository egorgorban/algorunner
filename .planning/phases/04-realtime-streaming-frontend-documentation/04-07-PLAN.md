## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-07-01 | Denial of Service | gateway request bodies | medium | mitigate | `client_max_body_size 128k` in front of the API's 100 000-byte cap (verified: 413 through the gateway) |
| T-04-07-02 | Tampering (XSS defense in depth) | gateway headers | medium | mitigate | CSP `default-src 'self'` with no inline script allowance, nosniff, frame-ancestors 'none' + X-Frame-Options DENY, Referrer-Policy no-referrer on every response (verified by the smoke check and the console check) |
| T-04-07-03 | Spoofing | cross-site WebSocket | low | mitigate | WS_ALLOWED_ORIGINS limits browser origins to localhost gateway and dev server; verified 4403 through the gateway |
| T-04-07-04 | Denial of Service | idle WebSocket drops | low | mitigate | `proxy_read_timeout`/`proxy_send_timeout 3600s` plus uvicorn's 20 s pings keep long LLM steps from severing sockets (Pitfall 4) |
| T-04-07-05 | Information Disclosure | dev compose host ports (5432, 6379, 3900, 8000) and plain HTTP | medium | accept | Local single-user Docker Compose deployment in v1; TLS termination and closing dev ports for a public deployment are recorded in DEFERRED.md (04-04) |
| T-04-07-06 | Tampering | base images | low | accept | Official Docker Library images (node, nginx) pinned to a major/variant tag; the npm tree comes from the approved lockfile via `npm ci` |
| T-04-07-07 | Information Disclosure | scripts/verify_phase4_live.py | low | accept | The script prints statuses, ids and check names only, never keys or env values |
</threat_model>

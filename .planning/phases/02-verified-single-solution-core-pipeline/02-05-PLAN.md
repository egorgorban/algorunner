    Create tools/python_executor/subprocess_backend.py per RESEARCH.md Pattern 3's verified code example, with these mandatory additions beyond the template:
    - A `_DENYLISTED_IMPORTS = {"os", "subprocess", "socket", "shutil", "sys", "ctypes", "multiprocessing", "threading"}` constant and a `_check_denylist(code: str) -> str | None` function using `ast.parse(code)` + walking `ast.Import`/`ast.ImportFrom` nodes, returning the first disallowed module name found (checking the top-level module, e.g. `os.path` still matches `os`) or `None` if clean. ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM-generated code -> real OS process execution | this plan is where generated content FIRST actually executes as a live process on the worker host — the highest-risk boundary in the whole phase |
| subprocess environment -> worker process environment | the spawned process must not inherit worker secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05-01 | Elevation of Privilege | tools/python_executor, tools/go_executor | high | mitigate | static AST/text-based import denylist (os/subprocess/socket/shutil/sys for Python; net/os-exec/syscall/unsafe for Go) rejects known-dangerous imports before any subprocess spawns; `RLIMIT_CPU`/`RLIMIT_AS`/`RLIMIT_NPROC=0` + `start_new_session`+`os.killpg` process-group kill bound what an unblocked process can do even if the denylist is incomplete — full sandboxing (SEC-02/SEC-03) is explicitly deferred to v2 per REQUIREMENTS.md "Out of Scope"; this is the documented minimum-viable interim control, not an accepted gap |
| T-02-05-02 | Information Disclosure | subprocess env passed to generated code | medium | mitigate | `env={}` (or a minimal explicit allowlist) on every `asyncio.create_subprocess_exec` call — generated code never inherits `OPENAI_API_KEY`/`DATABASE_URL`/`REDIS_URL` from the worker process |
| T-02-05-03 | Denial of Service | fork-bomb / runaway generated process | high | mitigate | `RLIMIT_NPROC=0` blocks `fork()` entirely; process-group timeout kill (`os.killpg` + `SIGKILL` fallback + `await proc.wait()` reap) bounds both a hung generated program and a hung `go build` invocation |

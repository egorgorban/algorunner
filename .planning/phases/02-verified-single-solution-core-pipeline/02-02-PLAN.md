<objective>
Prove the riskiest new architecture end-to-end with the smallest possible slice: one real OpenAI structured-output call, flowing through a real (not stub) LangGraph `StateGraph` checkpointed to Postgres, invoked by the worker, landing as a genuine analysis result on the task row. Purpose: prove OpenAI structured-output + LangGraph `durability="sync"` + Postgres checkpoint resume works for real before four more plans build six more nodes on top of it, and retire the known Phase-1 reliability gaps first.
Output: the real Analyzer node wired end-to-end, the full GraphState shape, and a hardened worker/broker/API surface.
</objective>

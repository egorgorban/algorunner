  <action>
    Create agents/code_generator/prompts.py: `build_code_messages(state) -> list[dict]` — system message instructs the model to translate `state["solver_output"]["algorithm"]` (the Solver's elaborated approach) into a correct, idiomatic Python implementation AND a correct, idiomatic Go implementation of the SAME algorithm, both solving the analyzed problem. Include a soft safety guideline (the real enforcement is Plan 02-04's static denylist, not this prompt): "the generated code runs unsandboxed — use only standard algorithmic/data-structure libraries (collections, itertools, heapq, bisect, math, functools, typing for Python; only the Go standard library, no filesystem/network/exec packages), never os/subprocess/socket/shutil/sys or Go's os/exec/net/syscall packages." Delimit `state["solver_output"]` as data, same prompt-injection framing as prior nodes.

    Create agents/code_generator/node.py: local `class CodeGenOutput(BaseModel): code_python: str = Field(..., min_length=1); code_go: str = Field(..., min_length=1)`. `async def code_generator_node(state: GraphState) -> dict` calls `call_structured(get_client(), model=model_for("code_generator"), messages=build_code_messages(state), response_format=CodeGenOutput)`, raises on `message.parsed is None`. Constructs the real `Solution`: `Solution(approach=state["solver_output"]["approach"], algorithm=state["solver_output"]["algorithm"], code_python=result.code_python, code_go=result.code_go, tests=[], complexity_time=state["solver_output"]["complexity_time"], complexity_space=state["solver_output"]["complexity_space"])`. Return `{"solution": solution}`.

    Create agents/test_generator/prompts.py: `build_test_messages(state) -> list[dict]` — system message instructs the model to generate additional test cases (input/output pairs matching the shape of `state["examples"]`) for `state["solution"].code_python`, explicitly including edge cases (empty input, boundary values, duplicates, D-12) — and to produce AT LEAST `settings.test_generator_min_tests` (10) of them when `state["examples"]` has fewer than 3 entries (D-11 — state this exact numeric floor in the prompt, do not leave it to model judgment). Delimit `state["solution"].code_python`/`state["examples"]` as data.

    Create agents/test_generator/node.py: local `class TestCase(BaseModel): input: str; output: str` and `class GeneratedTests(BaseModel): tests: list[TestCase]`. `async def test_generator_node(state: GraphState) -> dict` calls `call_structured(get_client(), model=model_for("test_generator"), messages=build_test_messages(state), response_format=GeneratedTests)`, raises on `message.parsed is None`. Merge in Python (D-10 — never trust the LLM to correctly echo provided examples back verbatim): `provided = [{"input": e["input"], "output": e["output"]} for e in state["examples"]]`, `generated = [{"input": t.input, "output": t.output} for t in result.tests]`, `merged = provided + generated`. Enforce D-11's floor explicitly in code (not just prompt instruction): `if len(state["examples"]) < 3 and len(generated) < settings.test_generator_min_tests: raise ValueError(f"Test Generator produced only {len(generated)} tests, below the required minimum of {settings.test_generator_min_tests} when fewer than 3 examples are provided")`. Return `{"solution": state["solution"].model_copy(update={"tests": merged})}`.

    Write tests/agents/test_code_test_gen.py: (1) code_generator_node with a mocked `CodeGenOutput` response produces a `Solution` whose `code_python`/`code_go` are non-empty and whose `tests` starts empty; (2) test_generator_node with 0 provided examples and a mocked `GeneratedTests` response of exactly 10 tests — assert `len(result["solution"].tests) == 10` and every provided example (empty set here) is present; (3) test_generator_node with 2 provided examples that MUST survive verbatim plus a mocked response of 10 generated tests — assert `len(result["solution"].tests) == 12` and the 2 provided examples appear unmodified in the merged list; (4) test_generator_node with 1 provided example and a mocked response of only 5 generated tests — assert `ValueError` is raised (D-11 shortfall guard).
